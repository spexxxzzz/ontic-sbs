# Ontic website

Static Ontic-branded showcase for `ontic.sbs`. This is the public marketing page only. It does not include image/video generation, sign-in, payments, or an API.

The page design and media are based on the public [2.71 Studio](https://studio.271.dev/) landing page. The linked [two-71/studio](https://github.com/two-71/studio) project is MIT-licensed; its generation app is not bundled here. Original media and brand assets remain attributed to their respective owners.

Contact: `pranit@ontic.sbs`

## Local preview

```sh
python3 -m http.server 3004
```

## GitHub Pages

Pages serves the root of the `main` branch. The `CNAME` file points it to `ontic.sbs`. DNS must be configured separately at the domain provider.
